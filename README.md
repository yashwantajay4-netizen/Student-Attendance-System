
# AttendEase - Student Attendance Management System

AttendEase is a simple, user-friendly Student Attendance Management System developed to make student attendance tracking easier, faster, and more organized.

The system allows users to register students, mark daily attendance, manage student records, view attendance statistics, and generate attendance reports through an interactive dashboard.

The main objectives of AttendEase are:

## 7. Installation and Setup

Follow these steps to run the AttendEase application.

### Step 1: Create a Project Folder

Create a folder named:

```text
AttendEase
```

### Step 2: Create the Required Files

Inside the project folder, create the following files:

```text
index.html
style.css
script.js
README.md
```

### Step 3: Add the Source Code

Copy the respective HTML, CSS, and JavaScript source code into their corresponding files.

Make sure that the filenames and extensions are correct.

### Step 4: Open the Project

Open the AttendEase folder in Visual Studio Code.

### Step 5: Run the Application

Open the `index.html` file in a web browser.

Alternatively, install the Live Server extension in Visual Studio Code.

Right-click `index.html` and select:

```text
Open with Live Server
```

The AttendEase application will open in your browser.

## 8. How to Use the Application

### Dashboard

Open the application to view the dashboard.

The dashboard displays:
- Total students.
- Present students.
- Absent students.
- Students whose attendance is not marked.
- Attendance progress.

### Register Students

1. Click the Register button.
2. Enter the student's details.
3. Fill in all required fields.
4. Click Register Student.
5. The student will be added to the student records.

### Mark Attendance

1. Click Mark Attendance.
2. View the registered student list.
3. Select Present or Absent for each student.
4. Click Save Attendance.
5. The attendance information will be saved.

### Manage Students

1. Click Students.
2. View the registered student list.
3. Search for a student using their name or roll number.
4. Manage the available student records.

### Generate Reports

1. Click Reports.
2. View the attendance history.
3. Check present and absent records.
4. Click Download CSV to download the report.

## 9. Data Storage

AttendEase uses browser Local Storage to maintain student and attendance information.

The advantages of Local Storage include:

- Data remains available after refreshing the page.
- No separate database installation is required.
- Student records can be stored directly in the browser.
- The application can run without a backend server.

**Note:** Local Storage is browser-specific. Data is not automatically synchronized between different devices or browsers. Clearing browser data may also remove saved records.

This project is intended for demonstration and academic purposes. It is not a replacement for a secure institutional attendance database.
